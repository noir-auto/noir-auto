# NOIR AUTO — Детейлинг нового уровня

Одностраничный сайт студии ухода за автомобилями. Тёмный визуальный стиль, бордовые акценты и выразительная типографика поддерживают премиальную подачу услуг.

**Открыть сайт:** https://noir-auto.github.io/noir-auto/

## Разделы сайта

- О студии и её подходе к уходу за автомобилем.
- Услуги с ориентировочными ценами: мойка, полировка, химчистка, керамическое покрытие и комплексный уход.
- Галерея автомобилей.
- Этапы работы и ответы на частые вопросы.
- Контактный блок с кнопкой звонка мастеру.

## Возможности

- Адаптация под мобильные устройства.
- Навигация по разделам сайта.
- Интерактивные блоки с вопросами и ответами.
- Быстрый звонок мастеру с сайта.

## Технологии

HTML, CSS, JavaScript, GitHub Pages.

## Примечание

Цены и номера на сайте указаны для демонстрации и требуют согласования с мастером. Фотографии в галерее иллюстративные — перед реальным использованием их следует заменить фотографиями выполненных работ.
